⚙️ Settings System Demo

Welcome

This is a minimal, production-ready settings system that includes theme switching with localStorage persistence. Switch between dark and light modes using the toggle button in the header.

The theme preference is automatically saved and restored on page reload. No external dependencies required — just vanilla JavaScript and CSS.

Features

✓ Built-in

  • ✅ Dark and Light themes
  • ✅ localStorage persistence
  • ✅ Smooth CSS transitions

💡 Tip: You can easily extend this system to include additional settings like font size, color scheme, language, etc. Just add them to the defaults object in settings.js.

Usage Examples

JavaScript API

// Initialize (auto on page load)
Settings.init();

// Toggle theme
Settings.toggleTheme();

// Get current theme
const theme = Settings.getTheme();  // Returns 'dark' or 'light'

// Set a setting
Settings.setSetting('theme', 'light');

// Get a setting
const theme = Settings.getSetting('theme');

// Get all settings
const all = Settings.getAll();

// Reset to defaults
Settings.reset();

// Listen for changes
window.addEventListener('themeChanged', (event) => {
  console.log('New theme:', event.detail.theme);
});

HTML Integration

<!-- Theme toggle button -->
<button id="theme-toggle" type="button">🌙</button>

<!-- Auto-initializes on page load -->
<script src="static/js/settings.js"></script>

CSS Variables

/* Use in your CSS */
body {

  color: var(--text-primary);
}

button {
  background-color: var(--accent);

}

/* Themes automatically update all variables */

Performance & Best Practices

Optimizations

  • ⚡ Runs in IIFE to avoid global scope pollution
  • ⚡ CSS transitions suppressed during initial load (no FOUC)
  • ⚡ requestAnimationFrame used for smooth transitions
  • ⚡ Error handling for localStorage access
  • ⚡ Minimal DOM queries and updates
  • ⚡ Single stylesheet with CSS custom properties
📊 Size: ~2.5 KB JavaScript + ~3 KB CSS (uncompressed). Gzipped: ~1 KB JavaScript + ~1.2 KB CSS.

Quick Integration Guide

Step 1: Include Files

Step 2: Add HTML Elements
